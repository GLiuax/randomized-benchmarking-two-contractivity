**Author:** Ao-Xiang Liu

Research manuscript on two-copy contractivity, unitarity, and finite-length sampling bounds for randomized benchmarking.

## Build

With a TeX distribution containing REVTeX 4.2, PGFPlots, and `latexmk`, run:

```sh
latexmk -pdf -interaction=nonstopmode -halt-on-error rb_two_copy_contractivity.tex
```

Keep the bibliography file in the same directory as the LaTeX source.
